import xml.etree.ElementTree as ET
import csv

def xml_to_csv(xml_file, csv_file,headers):
    tree = ET.parse(xml_file)
    root = tree.getroot()
    
    with open(csv_file, 'w', newline='', encoding='utf-8') as csvfile:
        writer = csv.writer(csvfile)
        # row = root.find("row")
        # # Write headers
        # headers = row.attrib.keys()
        writer.writerow(headers)

        # Write data rows
        for row in root.findall("row"):
            values = []
            for header in headers:
                now_value = row.attrib.get(header)
                if type(now_value) == str:
                    values.append(now_value.replace("\n", " ").replace("\r", " ").replace("\t", " ").replace(",", " "))
                else:
                    values.append(now_value)
            writer.writerow(values)

def lonlat_to_mercator(lon, lat):
    k = 6378137

    return x, y

Conlusion

  1. Temporal Patterns of User Registrations
  • Initial Spike: In the early years (around 2010 - 2011), there is a significant spike in user registrations, suggesting a period of high - interest or effective marketing efforts that attracted a large number of new users.
  • Fluctuations: After the initial spike, user registrations exhibit significant fluctuations over time. There are multiple peaks and troughs, indicating that the rate of new user sign - ups is not stable. These fluctuations could be due to various factors such as changes in marketing campaigns, external events, or competition.
  • Decline: Starting from around 2018, there is a general decline in user registrations, with the number of new users gradually decreasing towards 2024. This might imply that the platform is facing challenges in attracting new users or that the market has become saturated.
  1. Temporal Patterns of Posts
  • Lower Activity Level Compared to Registrations: The number of posts is generally lower than the number of user registrations throughout the period. This could mean that not all registered users are actively creating posts.
  • Fluctuations: Similar to user registrations, the number of posts also fluctuates over time. There are some peaks and troughs, but the amplitude of these fluctuations is relatively smaller compared to user registrations.
  • Decline: From around 2020, there is a noticeable decline in the number of posts, which may be related to the overall decline in user activity or changes in user behavior on the platform.
  1. Relationship between User Registrations and Posts Initial Correlation: In the early years, there seems to be some correlation between user registrations and posts. For example, around 2011 - 2012, when there are spikes in user registrations, there are also corresponding increases in the number of posts. This could suggest that new users are actively engaging with the platform by creating posts shortly after registration. Divergence: As time progresses, the relationship between user registrations and posts becomes less clear. After 2018, while user registrations are in a more consistent decline, the number of posts has its own pattern of decline and fluctuations, indicating that other factors may be influencing post - creation behavior.

def boxPlot(k,box_plot,mean_blood_pressure):
    # print(k)
    qmin, q1, q2, q3, qmax = np.percentile(mean_blood_pressure, [0, 25, 50, 75, 100])
    out = mean_blood_pressure[(mean_blood_pressure > q3 + 1.5 * (q3 - q1)) | (mean_blood_pressure < q1 - 1.5 * (q3 - q1))]
    iqr = q3 - q1
    upper = q3 + 1.5 * iqr
    lower = q1 - 1.5 * iqr

    # print(f"qmin: {qmin}, q1: {q1}, q2: {q2}, q3: {q3}, qmax: {qmax}")
    upper = min(qmax, upper)
    lower = max(qmin, lower)

    hbar_height = (qmax - qmin) / 500

    if not out.empty:
        outlier = list(out.values)

    # stems
    box_plot.segment(upper, [k], q3, [k], line_color="black")
    box_plot.segment(lower, [k], q1, [k], line_color="black")

    # boxes
    box_plot.hbar([k], 0.7, q2, q3, line_color="black")
    box_plot.hbar([k], 0.7, q1, q2, line_color="black")

    # whiskers (almost-0 height rects simpler than segments)
    box_plot.rect(lower, [k], 0.2, hbar_height, line_color="black")
    box_plot.rect(upper, [k], 0.2, hbar_height, line_color="black")



    source = ColumnDataSource(data=dict(y=[k] * mean_blood_pressure.shape[0],x=mean_blood_pressure))
    box_plot.scatter('x', 'y', size=6, fill_alpha=0.6, color="blue", source=source)
    if not out.empty:
        box_plot.scatter(outlier, [k] * len(outlier),  size=6, fill_alpha=0.6, color="orange")

Conclusion and Consideration on data privicy and ethic problem

  1. User - related data across the plots poses multiple privacy risks. In “User Activity Over Time”, user registration and post - creation dates can potentially be used to identify individuals when combined with other data, while the “Post Score vs Comment Count” plot’s underlying user - generated content may reveal personal identities and opinions. Vote - type data in “Vote Type Distribution” can expose unique user voting patterns, and tag - related data in “Top Tags Analysis” may allow for user identification through specific tag combinations. Post - lifetime data in “Lifetime of Posts” plots can disclose long - term user interests and activity patterns, all of which can be misused if not properly safeguarded.
  2. Ethical considerations are also significant. Analyzing this data must adhere to platform terms and user expectations, avoiding misuse for behavioral analysis or third - party sharing. It should not be used to target, discriminate against, stigmatize, or disadvantage users. Additionally, the data should not be employed to harass or unduly pressure users. To mitigate these issues, proper anonymization, transparent data usage policies, and obtaining user consent (when necessary) are essential during the data analysis process.
